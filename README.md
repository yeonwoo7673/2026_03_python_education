# 🐍 Python OOP 퀴즈 게임
> **특강: Git과 함께 하는 Python 첫 발자국**  
> 객체지향 프로그래밍(OOP) 원리를 적용하고 Git 워크플로우를 실습하기 위한 프로젝트입니다.

## 📝 프로젝트 개요
이 프로젝트는 단순한 퀴즈 프로그램을 넘어, 데이터를 구조화하고 유지보수하기 쉬운 코드를 작성하는 연습을 위해 제작되었습니다. 클래스 설계부터 예외 처리, JSON 데이터 영속성 관리, 그리고 Git을 활용한 버전 관리까지의 전 과정을 포함합니다.

## ✨ 주요 기능
- **객체지향 설계 (OOP)**: `Quiz` 클래스와 `QuizGame` 클래스를 분리하여 데이터와 로직을 캡슐화했습니다.
- **데이터 영속성 (Persistence)**: `state.json` 파일을 통해 프로그램 종료 후에도 퀴즈 목록과 최고 점수가 보존됩니다.
- **퀴즈 관리 시스템**: 사용자가 직접 퀴즈를 추가하고, 현재 등록된 전체 퀴즈 목록을 확인할 수 있습니다.
- **점수 시스템**: 퀴즈 완료 시 현재 점수를 계산하고, 기존 최고 점수를 경신할 경우 자동으로 업데이트합니다.
- **견고한 예외 처리**: 잘못된 메뉴 선택, 숫자가 아닌 입력, 파일 누락 등의 상황에서도 프로그램이 비정상 종료되지 않도록 설계되었습니다.

## 🛠 기술 스택
- **Language**: Python 3.11.6
- **Data Storage**: JSON
- **Version Control**: Git & GitHub

## 🏗 클래스 구조
- `Quiz`: 개별 퀴즈의 질문과 정답 데이터를 관리하는 모델 클래스
- `QuizGame`: 게임의 흐름 제어, 파일 입출력, 메뉴 렌더링을 담당하는 컨트롤러 클래스
