# 🐍 Python OOP 퀴즈 게임
파이썬 객체지향 프로그래밍(OOP)을 학습하기 위해 만든 간단한 콘솔 퀴즈 게임입니다.

## ✨ 주요 기능
- **퀴즈 풀기**: 등록된 퀴즈를 풀고 점수를 확인합니다.
- **최고 점수 기록**: 최고 점수는 `state.json`에 저장되어 유지됩니다.
- **퀴즈 관리**: 새로운 퀴즈를 추가하거나 전체 목록을 볼 수 있습니다.
- **데이터 보존**: 모든 데이터는 JSON 형식으로 자동 저장됩니다.

## 🛠 사용 기술
- Python 3.x
- JSON (Data Storage)
- Git (Version Control)
